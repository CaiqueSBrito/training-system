# Specs vivas

Uma pasta por capacidade (`governanca/specs/<capacidade>/spec.md`), no formato de `governanca/modelos/spec.md`. Descrevem como o sistema **é**; só mudam ao arquivar uma mudança (etapa 8 do pipeline).

O ID de requisito é único em todas as specs; o validador recusa duplicata.

| Capacidade | Spec | Requisitos |
| --- | --- | --- |
| chat | [chat/spec.md](chat/spec.md) | 22 (`RAG-*`, `SEC-*`, `OBS-*`) |
| ingestão | [ingestao/spec.md](ingestao/spec.md) | 6 (`ING-*`) |
